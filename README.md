# BadgerUtils
Utilities used by BadgerBOTS in robot code

## Installation

Add 
```
https://raw.githubusercontent.com/team1306/badger-utils/main/vendordep.json
```

The 2027.0.4 release targets WPILib 2027 Alpha 7. Install the Alpha 7 WPILib tools and use
AdvantageKit 27.0.0-alpha-5 and Phoenix 6 26.70.0-alpha-2 in the robot project. Systemcore
deployment requires image 14 or newer.
